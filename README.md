# quicknotes-app

QuickNotes is a simple note-taking web app built with HTML, CSS and JavaScript. It allows you to write short notes, give each one a category, search through them, and delete them. Your notes are saved in the browser, so they are still there after you refresh the page.

## Features

- Add notes with a category (Personal, Work or Study)
- Each category has its own coloured card
- Delete a single note or clear all notes
- Search notes as you type
- Validation for empty notes and notes over 200 characters
- Note count message
- Notes saved with localStorage
- Works on phones and computers



## What I learned

- How to build a page with semantic HTML tags and linked labels.
- How to use Flexbox and a media query to make a layout responsive.
- How to create elements with `createElement` and `textContent` instead of `innerHTML`.
- How to save and load data with `localStorage`, `JSON.stringify` and `JSON.parse`.
